Doom Sandbox Options Worksheet
==============================
Edit this file. Whatever remains is what DoomSandbox should implement.

- Delete a row = that option is removed
- Change Name / Default / Choices / Does = that option is rewritten
- Add a row under a tab = new option on that tab
- Add a new TAB section = new sandbox tab

Format: Name | Default | Choices | Does
