--------------------------------------------------------------------

TEMP SPEC PURPOSE

This file is the full command/response script spec used to structure implementation work.
Use COMMANDS-README.md for player/admin-facing general command guidance.

Locked names:
    Mod folder:     AGF-NoEAC-VisualEntityTrackerAddon
    Player label:   Visual Entity Tracker
    Chat roots:     /agfvet (player-facing), /agf-vet (alias)
    Console root:   agf-vet
    Console prefix: [VisualEntityTracker]

Requires AGF-HUDPlus-VisualEntityTracker on the same server.
This DLL does not draw compass markers. It only lets each player turn
XML Visual Entity Tracker on or off for themselves.

EnhancedAGF ESC/UI is deferred. This spec is chat + F1 console only.
No COUNT mode.

--------------------------------------------------------------------

CHAT Commands (Server Baseline)

Status / help is two separate whispers, matching Screamer Alert:
    Line 1 = current mode
    Line 2 = options
(Screamer Alert also has a third COUNT line. This mod does not.)

    Command: /agfvet, /agf-vet, /agfvet help, /agf-vet help, /agfvet status, /agf-vet status
    Response (two whispers):
        [Visual Entity Tracker = <OFF|ON>]
        [Options: /agfvet off, on]

    Command: /agfvet on, /agf-vet on
    Response: [Visual Entity Tracker = ON]

    Command: /agfvet off, /agf-vet off
    Response: [Visual Entity Tracker = OFF]

    Command: /agfvet <invalid>, /agf-vet <invalid>
    Response: [ERROR][Use /agfvet]

Admin CONSOLE Commands for Visual Entity Tracker (Full Script Spec)

    Quick Use:
        1. agf-vet
        2. agf-vet default <off|on>
        3. agf-vet set <entityId|all> <off|on|default>
        4. agf-vet list

    Command: agf-vet, agf-vet help, agf-vet default
    Response (multi-line):
        [VisualEntityTracker] Usage:
        [VisualEntityTracker]   agf-vet default <off|on>
        [VisualEntityTracker]   agf-vet set <entityId|all> <off|on|default>
        [VisualEntityTracker]   agf-vet list
        [VisualEntityTracker] default currently set to [OFF|ON]

    Command: agf-vet default on
    Response: [VisualEntityTracker] default set to ON. New joining players will start with Visual Entity Tracker set to ON.

    Command: agf-vet default off
    Response: [VisualEntityTracker] default set to OFF. New joining players will start with Visual Entity Tracker set to OFF.

    Command: agf-vet default <invalidMode>
    Response: [VisualEntityTracker] invalid option. Use: agf-vet default <off|on>.

    Command: agf-vet set <entityId> on
    Response: [VisualEntityTracker] entity=<entityId> (<playerName>) mode set to ON.

    Command: agf-vet set <entityId> off
    Response: [VisualEntityTracker] entity=<entityId> (<playerName>) mode set to OFF.

    Command: agf-vet set <entityId> default
    Response: [VisualEntityTracker] entity=<entityId> (<playerName>) set to current default=<OFF|ON>.

    Command: agf-vet set all on
    Response: [VisualEntityTracker] all online players set to ON. default unchanged.

    Command: agf-vet set all off
    Response: [VisualEntityTracker] all online players set to OFF. default unchanged.

    Command: agf-vet set all default
    Response: [VisualEntityTracker] all online players set to current default=<OFF|ON>.

    Command: agf-vet list
    Response (multi-line):
        [VisualEntityTracker] <index>. id=<entityId>, <playerName>, vet=<OFF|ON>
        [VisualEntityTracker] total online=<N>

    Command: agf-vet set <invalidEntityId> <off|on|default>
    Response: [VisualEntityTracker] invalid entityId. Use numeric entityId or all.

    Command: agf-vet set all <invalidMode>
    Response: [VisualEntityTracker] invalid mode. Use: agf-vet set all <off|on|default>.

    Command: agf-vet set <entityId|all> <invalidMode>, agf-vet <invalid>
    Response: [VisualEntityTracker] invalid option. Use: agf-vet help.

    Command: agf-vet <anything> (non-admin)
    Response: [VisualEntityTracker] admin permission required.

    Notes:
        set all applies to online players only.
        default controls baseline behavior for new joiners.
        set <entityId|all> default applies the current default value immediately.
        Default for first-time players is ON (same as XML Visual Entity Tracker).
        Preference is saved per player so death/rejoin does not turn it back on
        unless they (or an admin) change it.
        XML Visual Entity Tracker still adds buffZAlert on spawn. If the saved
        mode is OFF, this DLL removes that buff for that player.
