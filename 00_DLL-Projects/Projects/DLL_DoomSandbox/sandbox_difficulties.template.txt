Doom Sandbox Difficulty Presets
===============================
Fill one DIFFICULTY block per preset. These become Difficulty-group sandbox presets.
Legal values must match Choices in sandbox_options.txt (Locked tabs are NOT listed —
those are forced the same for every difficulty).

Fields:
  Name: <display name>           shown in the preset spinner (e.g. Be Gentle!)
  Rating: <int>                  1 = easiest, higher = harder (difficulty_rating)
  Default: true|false            optional; only one should be true (new-game pick)
  Description: <text>            shown under the preset
  Icon: <path>                   optional; blank = shared Doom art / vanilla fallback

Real preset blocks start after the long ==== divider below.
Do not put example DIFFICULTY lines in this header — they get loaded as presets.

Per-option rows (editable tabs only):
  Name | Value

Copy a whole DIFFICULTY block to add another tier. Leave a value blank to mean
"use worksheet Default from sandbox_options.txt".
